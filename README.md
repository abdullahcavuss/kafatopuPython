# Head Ball (Python)

A 2D Head Ball game built with Pygame. Originally started 6 years ago and now finished thanks to AI.

## Controls

| Player | Move | Jump | Shoot |
| :--- | :--- | :--- | :--- |
| **Player 1 (Left)** | `A` / `D` (or `Left` / `Right`) | `W` (or `Up`) | `Space` / `F` |
| **Player 2 (Right)** | `Left` / `Right` | `Up` | `Enter` / `Down` |

- `P`: Pause / Resume
- `R`: Restart match
- `ESC`: Back to menu / Exit

## Installation & Run

Install dependencies:
```bash
pip install pygame
```

Run the game:
```bash
python app.py
```
